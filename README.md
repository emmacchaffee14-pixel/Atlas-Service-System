# Atlas-Service-System
Streamline the Atlas service experience.

Redesign of the Atlas Business Society (UGA) service-events workflow, replacing three disconnected
sources of truth (editable sheet + logistics form + attendance form) with a single signup path,
automatic capacity/waitlist handling, QR/roll-call attendance, and automatic service-hours reporting.

## Status
Architecture phase complete. No implementation code has been written yet — see `docs/architecture.md`
for the full system design and `docs/requirements.md` for the requirements it was built against.
Implementation begins at Milestone 1 (data model + core sheets) per the roadmap in the architecture doc.
